# 🌼 花鄉田尾 Tianwei — The Flower Town of Taiwan

**🔗 網站：<https://tianwei.efetl.com>**

彰化縣田尾鄉的多語家鄉介紹網站，讓三年級到高中的學生認識自己的家鄉，同時學英文；也讓外國朋友用自己的語言認識田尾。

> 本網站為**個人製作、非官方、非商業**的家鄉介紹，用於教學。只介紹公共景點，不介紹店家。

## 內容

| 區塊 | 說明 |
|---|---|
| 認識田尾 | 地名由來（濁水溪灌溉水圳下游、「田的尾端」）、花卉產業 |
| 花鄉的故事 | 時間軸：百年前巫修齊從漳州帶回種子 → 花木交換 → 日治時期職業化 → 1973 公路花園誕生（原名「公路公園」）→ 休閒園區；附三級英文故事 |
| 四大公共景點 | 田尾公路花園、菊花不夜城、海豐崙彩繪村、騎單車遊花鄉 |
| 補充景點 | 怡心園遊戲場、在地廟宇（國聖宮、沛霖宮）、台1線 |
| 相片牆 | 田尾四季花卉 |
| 學英文 | 花鄉英文單字表（點擊發音）＋ 8 題小測驗 |

## 功能

- **中文 ＋ 第二語言切換**：English／日本語／ไทย（泰文）／Bahasa Indonesia
- **英文三級難度**：🌱 Level 1 國小　🌿 Level 2 國中　🌳 Level 3 高中
- **真人質感發音**：微軟 Edge 神經語音 `en-US-AvaNeural`，預先產生 MP3，各裝置聲音一致
- **響應式設計**：手機、平板、電腦都能看；全站最小字體 18px
- 支援深色模式

## 檔案結構
